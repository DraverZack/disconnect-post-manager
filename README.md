# Disconnect Post Manager — Cloudflare Edition

Личный Telegram-публикатор для канала. Работает в **Cloudflare Workers**, хранит черновики и настройки в **Cloudflare D1**, поэтому компьютер держать включённым не нужно.

## Что умеет версия 1.1

- черновики, готовые посты и архив без обязательной даты публикации;
- ручная публикация в любой момент;
- текст, фото, видео, GIF/анимации и документы;
- сохранение Telegram-форматирования (`entities`);
- редактирование текста/подписи опубликованного поста;
- замена медиа опубликованного медиа-поста там, где это разрешает Telegram;
- inline-кнопки и изменение их ссылок после публикации;
- стандартные, синие, зелёные и красные кнопки;
- попытка использовать Telegram custom emoji как иконку кнопки с автоматическим fallback;
- комментарии для каждого поста отдельно через связанную группу обсуждений;
- включение/выключение preview ссылок;
- публикация со звуком или без звука;
- SQLite-подобная SQL-база D1;
- сессии хранятся в D1, поэтому можно начать работу с телефона и продолжить с другого устройства.

> Пока не поддерживаются альбомы из нескольких фото/видео в одном посте. Это можно добавить следующей версией.

# Самый простой запуск: GitHub + Cloudflare, без терминала

## 1. Сначала тестовый бот

Для первой проверки лучше создать временного бота через **@BotFather** и использовать его токен. Основной `@DisconnectGame_bot` пока оставь подключённым к Controller Bot.

Никому не отправляй токен бота и не добавляй его в GitHub.

## 2. Создай private-репозиторий GitHub

Например:

`disconnect-post-manager`

Загрузи **содержимое этой папки** в корень репозитория:

- `src/`
- `package.json`
- `wrangler.jsonc`
- `schema.sql`
- `.gitignore`
- `README.md`

Файл `.dev.vars.example` можно загрузить — настоящих секретов в нём нет.

## 3. Подключи GitHub к Cloudflare Workers

В Cloudflare Dashboard:

1. **Workers & Pages**
2. **Create application**
3. **Import a repository**
4. Подключи GitHub
5. Выбери репозиторий `disconnect-post-manager`
6. Deploy command оставь стандартным: `npx wrangler deploy`
7. Нажми **Save and Deploy**

В `wrangler.jsonc` уже есть D1 binding `DB` без жёстко заданного ID. Современный Wrangler умеет автоматически создать D1-ресурс при деплое. Если Cloudflare попросит подтверждение/настройку D1 — оставь binding с именем **DB**.

### Если D1 автоматически не создалась

Это fallback-вариант:

1. Cloudflare → **D1 SQL Database** → **Create database**
2. Создай базу, например `disconnect-post-manager-db`
3. Worker → **Settings → Bindings → Add binding → D1 database**
4. Variable name: `DB`
5. Выбери созданную базу

Таблицы вручную создавать не требуется: Worker создаёт их при первом обращении. `schema.sql` лежит в проекте только как читаемая копия схемы.

## 4. Добавь 3 секрета Cloudflare

Worker → **Settings → Variables and Secrets → Add**.

Все три лучше создать типом **Secret**:

### `BOT_TOKEN`

Токен из BotFather.

### `SETUP_CODE`

Любой длинный личный код, например:

`My-DPM-Setup-2026-Change-Me`

Он используется только для первоначальной активации и защищённых служебных страниц.

### `WEBHOOK_SECRET`

Случайная строка. Используй только латинские буквы, цифры, `_` и `-`.

Например:

`dpm_9F7x_2Lq8_pQ31_2026`

После добавления секретов нажми **Deploy**.

## 5. Подключи Telegram webhook

Открой страницу своего Worker. Cloudflare покажет адрес примерно такого вида:

`https://disconnect-post-manager.<твой-subdomain>.workers.dev`

Добавь в конец:

`/setup?code=ТВОЙ_SETUP_CODE`

Пример структуры:

`https://disconnect-post-manager.example.workers.dev/setup?code=My-DPM-Setup-2026-Change-Me`

Если всё хорошо, увидишь JSON с:

- `"ok": true`
- именем бота;
- адресом webhook;
- `pending_update_count`.

Страница `/setup` сама вызывает Telegram `setWebhook`, поэтому терминал и curl не нужны.

## 6. Назначь себя владельцем

В Telegram открой своего бота и отправь:

`/claim ТВОЙ_SETUP_CODE`

После этого появится главное меню.

## 7. Подключи канал

Сначала добавь бота администратором канала.

Для полного набора функций ему нужны права на:

- публикацию сообщений;
- редактирование сообщений;
- удаление сообщений.

В боте:

**⚙️ Настройки → Подключить канал**

и отправь `@username` канала, ID или перешли пост из канала.

## 8. Комментарии

Если у канала есть связанная группа обсуждений, добавь бота администратором и туда. Для возможности выключать комментарии у отдельного поста боту нужно право удалять сообщения.

Механика такая:

- `💬 Комментарии: вкл.` — автоматическая копия поста в discussion group остаётся;
- `💬 Комментарии: выкл.` — бот ловит автоматическую копию и удаляет её, тем самым убирая ветку комментариев для этого поста.

# Проверка состояния

Есть защищённая диагностическая страница:

`/status?code=ТВОЙ_SETUP_CODE`

Она показывает:

- отвечает ли бот Telegram;
- установлен ли webhook;
- количество ожидающих update;
- был ли выполнен `/claim`;
- подключён ли канал;
- последнюю ошибку webhook, если Telegram её сообщает.

# Переход с Controller Bot на основной бот

Делай это только после успешного теста.

1. `@BotFather` → основной бот → **API Token**.
2. Отозви старый токен и получи новый. Это важно, потому что старый токен был передан Controller Bot.
3. В Cloudflare замени `BOT_TOKEN` на новый.
4. Deploy.
5. Снова открой `/setup?code=...` — webhook переключится на Cloudflare.
6. Открой Telegram → `/start`.
7. Подключи основной канал через ⚙️ Настройки.

После этого Controller Bot для публикации через этого бота больше не нужен.

# Безопасность

- `BOT_TOKEN`, `SETUP_CODE` и `WEBHOOK_SECRET` не должны лежать в GitHub.
- В GitHub есть только `.dev.vars.example` с фальшивыми значениями.
- Telegram-запросы принимаются только на `/telegram` и проверяются по `X-Telegram-Bot-Api-Secret-Token`.
- После `/claim` интерфейс бота доступен только одному Telegram user ID владельца.
- `/setup` и `/status` защищены `SETUP_CODE`.

# Автоматические обновления

После подключения GitHub к Workers Builds каждый push в production-ветку автоматически разворачивает новую версию Worker.

Данные черновиков находятся не в GitHub, а в D1, поэтому обновление исходного кода не удаляет архив и посты.

## v1.2 — Библиотека иконок

В настройках появилась `🧩 Библиотека иконок` для YouTube, Twitch, Telegram, Discord, Boosty и VK.

Для каждого сервиса один раз отправь нужный Telegram custom emoji. Бот сохранит его `custom_emoji_id` в D1 и затем позволит выбирать эту иконку для любой кнопки одним нажатием.

Если при создании новой кнопки в ссылке распознаётся сервис (например, `youtube.com`) и для него уже сохранена иконка, бот подставит её автоматически.
